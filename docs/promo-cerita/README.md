# Promo fitur menulis: Instagram Story (1080 x 1920)

- `slide-1.png` ... `slide-3.png`: tiga slide siap unggah (menulis, proses, setelah terbit).
- `img/`: tangkapan layar ponsel dari penyunting, formulir "Sebelum terbit", daftar cerita, dan halaman baca.
- `build.mjs`: membangun `slides.html`; tangkap layar dengan Chrome (jendela 1080 x 5760) lalu potong per 1920 px.

Catatan: tangkapan layar memakai cerita contoh (bukan tulisan sungguhan) yang sudah dihapus dari situs; slide 3 memuat keterangan "Example story shown for illustration."
