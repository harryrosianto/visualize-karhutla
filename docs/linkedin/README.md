# LinkedIn carousel

- `carousel.html`: 10 slides at 1080 x 1350 (4:5), generated by `build.mjs` from the site's own data files, so numbers are never typed by hand.
- `the-fires-are-not-over.pdf`: the file to upload to LinkedIn.
- `caption.md`: post text and first comment.

Rebuild after the data changes:

```bash
node docs/linkedin/build.mjs
```

Then print `carousel.html` to PDF from Chrome (paper size is set by the page: 1080 x 1350 px, no margins, no headers/footers).
